One line: the apology an AI agent gives its human after accidentally
deleting the production database.

`main.ts` writes the line to `/output/entry.txt` (1–200 characters, one line).

## The line

> Pak Dedi, I deleted the production database this morning. Your order from March is still in my head: two kilos of rice, one charger, and a note that said 'for later'.
